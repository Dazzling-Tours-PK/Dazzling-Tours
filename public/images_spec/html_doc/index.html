  • Recommended Format: WebP (quality 80–85%) for best loading speed, or standard high-res JPEG.
  • Logos: Deliver transparent PNG and/or vector SVG.
  • File Size Target: Keep page headers & hero under 300 KB each. Keep square collage images under 120 KB each.
  • Direct Replacement: If uploaded using the exact paths/filenames listed above, the website will update immediately without code changes.
